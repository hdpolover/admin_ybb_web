# Cache Key Reserved Characters Fix - Complete Implementation

## Issue Identified

The application was experiencing cache operation failures due to reserved characters in cache keys generated by the `RedisCacheService`. The error messages showed:

```
ERROR - Cache GET error for key localhost:8080:api:web-settings:043eef3a8638d0b718e66d6589307eb7:v1: Cache key contains reserved characters {}()/\@:
ERROR - Cache SET error for key localhost:8080:api:programs:category:4:cf20acabc5a0578c74c5e5c3fdf229d8:v1: Cache key contains reserved characters {}()/\@:
```

## Root Cause

CodeIgniter's cache system prohibits certain characters in cache keys:
- `{}` (curly braces)
- `()` (parentheses) 
- `/` (forward slash)
- `\` (backslash)
- `@` (at symbol)
- `:` (colon)

The `RedisCacheService` was generating keys with colons (`:`) as separators and including the port number from `$_SERVER['HTTP_HOST']` (e.g., `localhost:8080`), which caused all cache operations to fail.

## Solution Implemented

### 1. Domain Sanitization

Added `sanitizeDomain()` method to clean the domain part:

```php
private function sanitizeDomain(string $domain): string
{
    // Remove port number and replace reserved characters
    $domain = preg_replace('/:\d+$/', '', $domain); // Remove port
    $domain = preg_replace('/[{}()\\/\\@:]/', '_', $domain); // Replace reserved chars
    $domain = preg_replace('/[^a-zA-Z0-9_.-]/', '_', $domain); // Keep only safe chars
    return $domain;
}
```

**Results:**
- `localhost:8080` → `localhost`
- `example.com:80` → `example.com`
- `test@domain.com` → `test_domain.com`

### 2. Cache Key Sanitization

Added `sanitizeKey()` method to clean the entire cache key:

```php
private function sanitizeKey(string $key): string
{
    // Replace reserved characters with underscores
    $key = preg_replace('/[{}()\\/\\@:]/', '_', $key);
    // Ensure no double underscores
    $key = preg_replace('/_+/', '_', $key);
    // Remove leading/trailing underscores
    $key = trim($key, '_');
    return $key;
}
```

### 3. Updated Key Generation Format

Changed from colon-separated to underscore-separated format:

**Before:**
```
localhost:8080:api:web-settings:043eef3a8638d0b718e66d6589307eb7:v1
```

**After:**
```
localhost_api_web-settings_043eef3a8638d0b718e66d6589307eb7_v1
```

### 4. Updated Pattern Matching

Updated all cache invalidation patterns to use underscores:

**Before:**
```php
"participants:user:{$userId}"
"payments:participants:{$participantId}"
```

**After:**
```php
"participants_user_{$userId}"
"payments_participants_{$participantId}"
```

### 5. TTL Calculation Update

Updated TTL calculation to work with new key format:

```php

{
    $endpoint = ltrim($endpoint, '/');
    $endpoint = str_replace('/', '_', $endpoint); // Convert to underscore format
    
    // Check against patterns...
}
```
